# Balary exact-design live demo

This folder is built directly from the original Balary/ZalAry frontend source.

The landing-page visual layer and structure are preserved. The content has been aligned to Balary on Midnight, and landing CTAs route to `/demo`.

## Local preview

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the URL Vite prints, normally `http://localhost:5173/`.

- Landing: `/`
- Demo: `/demo`

## Design lock

No edits were made to the landing CSS files or favicon while adapting the content.
